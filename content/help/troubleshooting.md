## What this feature is

Troubleshooting collects conservative checks for the most common support areas while respecting account security and provider boundaries.

## Why it matters

Quality teams often troubleshoot under customer deadlines. A clear checklist helps separate user action, plan limits, temporary provider failures, and support escalation.

## When to use it

Use it when login codes fail, export is unavailable, AI returns an error, attachments do not upload, or checkout/payment status is confusing.

## Step-by-step operation

1. For login, request a fresh code and check the correct email alias without asking anyone to share verification codes.
2. For export, confirm report access, plan entitlement, and completion warnings.
3. For AI failure, keep the report saved and try again later; do not invent missing evidence.
4. For attachments, check file type, file size, role permissions, and report lock status.
5. For payment, confirm checkout status and contact support if entitlement does not update after provider confirmation.

## Example content

If AI Quality Check is temporarily unavailable, the report remains saved. Continue manual review and rerun the assistant later if needed.

## Common mistakes

- Sharing passwords, tokens, screenshots of verification codes, or payment secrets.
- Trying to bypass 2FA, CAPTCHA, scan login, or real-name verification.
- Assuming every error is data loss.
