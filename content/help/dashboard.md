## What this feature is

The dashboard is the home base after login. It lists reports, shows report status, exposes search and quota signals, and gives Team users a place to review seats and role assignments.

## Why it matters

Quality teams usually lose time hunting through email threads, file folders, and local spreadsheets. A report dashboard keeps active complaints, supplier issues, approval state, locks, and revision numbers visible before a customer asks for status.

## When to use it

Use it when you start the day, need to reopen an 8D, check whether a report is approved or locked, or confirm whether your plan still allows new report creation.

## Step-by-step operation

1. Log in and open Dashboard from the global header.
2. Use search or the report list to find the relevant customer complaint, supplier issue, or internal defect.
3. Review status, lock, revision, owner, and priority before editing.
4. Create a new report only when the issue is genuinely separate from existing work.
5. For Team, review member seats and invite or role controls from the workspace area.

A supplier quality engineer filters for a customer complaint, sees Rev.1 is approved and locked, then opens the report only to export the final package instead of editing the record.

## Common mistakes

- Creating duplicate reports for the same issue instead of reopening the existing record.
- Ignoring lock and revision indicators before making changes.
- Treating quota warnings as a billing error before checking plan limits.
