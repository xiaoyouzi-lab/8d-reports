## What this feature is

Evidence and attachments keep supporting files inside the report workflow instead of scattered across email threads and folders.

## Why it matters

A reviewer can understand why a decision was made when the file is attached to the relevant D-step.

## When to use it

Use it for defect photos, containment sort records, root-cause evidence, validation results, revised instructions, and customer documents.

## Step-by-step operation

1. Open the relevant D-step.
2. Choose camera, photo library, or file upload when editing is allowed.
3. Upload only evidence relevant to the report.
4. Use clear filenames so reviewers know what each file proves.
5. Before export, confirm the attachments belong in the delivery package.

See the page media reference for /help-assets/evidence-attachments/attachments.png. If the asset needs to be refreshed, run the Playwright capture script in scripts/capture-help-assets with an authenticated storage state.

## Example content

Attach coating peel photos in D2, sort sheet in D3, adhesion test result in D6, and updated checklist in D7.

## Common mistakes

- Uploading unrelated private files.
- Attaching evidence to the wrong D-step.
- Assuming attachments prove a claim without describing the result in the report text.
