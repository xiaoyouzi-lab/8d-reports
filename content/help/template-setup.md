## What this feature is

Template Setup is a service path for converting customer-specific 8D forms, merged Excel sheets, or company-controlled templates into a cleaner online workflow.

## Why it matters

Some customers require exact formats. A setup path keeps that request separate from standard export behavior and avoids overpromising generic export customization.

## When to use it

Use it when the standard PDF, Word, or Excel output is not enough for a customer-specific format.

## Step-by-step operation

1. Open the Custom 8D Template Setup page.
2. Collect sample Word or Excel templates and required customer rules.
3. Remove confidential data before sharing examples.
4. Submit the request through the contact path.
5. Review the setup scope manually before any production use.

## Screenshot or video reference

The screenshot above shows where this feature appears in the report workflow. Use it to match the guidance with the product screen. If your screen looks different, check your plan, role, report status, or workspace permissions.

## Example content

A supplier has a customer Excel workbook with 5-Why, action list, and signature sections. Template Setup evaluates how to map online fields to that format.

## Common mistakes

- Assuming standard export exactly matches every customer template.
- Uploading confidential templates without review.
- Treating setup as instant automation.
