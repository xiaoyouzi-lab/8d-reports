## What this feature is

Create New Report opens a new structured D0-D8 workspace. It should represent a real complaint, supplier corrective action, manufacturing defect, or recurring quality issue.

## Why it matters

The first screen sets the reporting scope. Clear product, customer, supplier, batch, owner, and priority details make the later D0-D8 content easier to review and export.

## When to use it

Use it when the issue needs a formal 8D / SCAR response, customer-ready export, evidence package, or team review path.

## Step-by-step operation

1. Open Dashboard and choose New report.
2. Enter a concise title that identifies the issue without exposing unnecessary private data.
3. Add report number, customer or supplier reference, product, batch, owner, and priority when available.
4. Save the report before writing long investigation content.
5. Move into D0 and D1 before filling later steps.

## Example content

Title: Brake bracket coating peel-off, Batch B26-041. Owner: Quality Engineering. Priority: High. Customer reference: CC-2026-118.

## Common mistakes

- Opening a report before confirming the problem really needs 8D structure.
- Using vague titles like customer issue or defect.
- Skipping owner and priority, which makes review responsibility unclear.
