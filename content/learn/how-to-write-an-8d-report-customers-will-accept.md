## Start with facts

D2 should define what failed, where it happened, when it happened, how many parts are affected, and what evidence supports the scope.

## Protect the customer first

D3 containment should explain how suspect product is blocked, sorted, rechecked, or controlled while investigation continues.

## Verify root cause

D4 should separate occurrence cause from escape cause. Use 5-Why or fishbone when they help, but do not present guesses as facts.

## Link actions to causes

D5 actions should trace back to D4. D6 should show implementation and validation results. D7 should show recurrence prevention across controls or similar processes.
