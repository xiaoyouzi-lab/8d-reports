# SEO Keyword Data Research Pipeline

## Purpose

This folder supports keyword research for 8D Reports SEO/GEO decisions before
any new public pages are created. It keeps candidate keywords, manual data
exports, SERP review notes, and generated opportunity reports in one place.

The pipeline must not fabricate search volume, CTR, CPC, competition,
difficulty, or ranking data. If a source file is missing or empty, the analysis
marks that source as missing data.

## Folder Layout

- `input/seed-keywords.csv` contains the candidate keyword pool.
- `input/*-template.csv` files define the expected import formats.
- `output/keyword-opportunity-report.csv` is generated by the analysis script.
- `output/keyword-opportunity-summary.md` is generated by the analysis script.

Copy exported data into these non-template files when available:

- `input/gsc-queries.csv`
- `input/keyword-planner.csv`
- `input/google-trends.csv`
- `input/serp-review.csv`

Do not commit account passwords, cookies, tokens, API keys, verification codes,
private customer data, or any secret material.

## Manual Export: Google Search Console Queries

1. Open Google Search Console for `https://www.8d-reports.com`.
2. Go to Performance > Search results.
3. Choose the target date range, such as last 28 days or last 3 months.
4. Filter country if the research is market-specific.
5. Export queries with clicks, impressions, CTR, and average position.
6. Save a cleaned CSV as `input/gsc-queries.csv` with columns:
   `query,clicks,impressions,ctr,position,country,date_range,source`.
7. Use `source` values such as `gsc_export_2026-07-02`.

## Manual Export: Google Ads Keyword Planner

1. Open Google Ads Keyword Planner.
2. Use Discover new keywords.
3. Paste the seed keywords from `input/seed-keywords.csv`.
4. Set the correct target market and language.
5. Export keyword ideas with average monthly searches, three-month change,
   year-over-year change, competition, and top-of-page bid range.
6. Save a cleaned CSV as `input/keyword-planner.csv` with columns:
   `keyword,avg_monthly_searches,three_month_change,yoy_change,competition,top_of_page_bid_low,top_of_page_bid_high,target_market,language,source`.

## Manual Export: Google Trends

1. Open Google Trends.
2. Compare small groups of related keywords, usually within one cluster.
3. Use the same geo and time range for each comparison group.
4. Record trend score, trend direction, and related queries.
5. Save a cleaned CSV as `input/google-trends.csv` with columns:
   `keyword,comparison_group,geo,time_range,trend_score,trend_direction,related_queries,source`.

## Manual Export: SERP Review

1. Search each high-priority candidate in an incognito or neutral browser.
2. Record the dominant result type: template, example, guide, software page,
   forum thread, video, marketplace listing, or mixed.
3. Note whether ads, AI Overview, and People Also Ask appear.
4. Summarize competitor strength without copying private or copyrighted content.
5. Save a cleaned CSV as `input/serp-review.csv` with columns:
   `keyword,top_results_summary,dominant_page_type,competitor_strength,has_ads,has_ai_overview,has_people_also_ask,notes,source`.

## Run Analysis

```bash
npm run analyze:seo-keywords
```

The command writes:

- `output/keyword-opportunity-report.csv`
- `output/keyword-opportunity-summary.md`

When real data is missing, the generated summary intentionally says so.
`commercial_intent_score`, `conversion_fit_score`, `content_gap_score`, and
`seed_fit_score` are seed-level heuristics only. The script only emits a real
`opportunity_score` when GSC or Keyword Planner data and SERP review data are
available. Google Trends can support a decision, but it does not unlock content
decisions by itself.

Use the summary as an operating checklist, not as permission to create pages
without data.
