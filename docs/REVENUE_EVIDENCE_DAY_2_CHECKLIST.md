# Revenue Evidence Day 2 Tracking Checklist

## Purpose

Use this checklist to track Day 2 manual distribution and outreach. Do not
auto-post. Do not record private customer, supplier, product, batch, report,
root-cause, corrective-action, lessons-learned, attachment, credential, payment,
or AI prompt content.

Safe tracking fields only:

- platform
- target page
- draft ready
- posted or sent
- time
- safe tracking note
- observed click
- observed reply
- next action

## Posting Gate

Do not publish or send any item unless all are true:

1. The platform account/session is already available.
2. No 2FA or account recovery is required.
3. The user explicitly allows that specific publish/send action.
4. The content has been manually reviewed.
5. The target platform rules allow the content and link behavior.
