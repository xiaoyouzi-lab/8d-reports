## 三、账号密码泄露风险评估

### 风险经理分析

#### ✅ 做得好的

| 安全措施 | 状态 | 详情 |
|---------|:---:|------|
| 密码传输加密 | ✅ | 全程 HTTPS，Vercel 自动 TLS |
| 密码前端不存储 | ✅ | 密码不入 localStorage/sessionStorage |
| Cookie HttpOnly | ✅ | `__Secure-better-auth.session_token` 设置 HttpOnly |
| Cookie Secure | ✅ | 生产环境使用 `__Secure-` 前缀，仅 HTTPS 传输 |
| Cookie SameSite | ✅ | SameSite=Lax，防 CSRF via 第三方站点 |
| 敏感文件保护 | ✅ | `.env` 返回 404，无 `NEXT_PUBLIC_` 变量泄露 |
| SQL 注入防护 | ✅ | 全部使用 Drizzle ORM 参数化查询，无原始 SQL |
| 注册防护 | ✅ | 种子数据已屏蔽 4 个临时邮箱域名 |

#### ⚠️ 需要修复的

| 风险项 | 严重程度 | 说明 |
|--------|:------:|------|
| **无认证速率限制** | 🔴 Critical | `/api/auth/sign-in/email` 无任何速率限制，可暴力破解密码。连续 1 分钟内可发起数百次登录尝试 |
| **密码策略仅前端校验 (8 字符)** | 🔴 Critical | 后端无密码强度验证，绕过前端可直接提交 `password: "a"`。无数字/大小写/特殊字符要求 |
| **Open Redirect 漏洞** | 🔴 Critical | `callbackUrl` 未经验证直接用于重定向，可实施钓鱼攻击 |
| **无电子邮件验证** | 🟡 Medium | 任何邮箱都可注册，无法确认邮箱归属；用户忘记密码时无法恢复 |

## 四、报告资料泄露风险评估

### 风险经理分析 — 🔴 不放行

| 风险项 | 严重程度 | 现状 |
|--------|:------:|------|
| **报告数据仅在 localStorage** | 🔴 Critical | 所有报告数据明文存储在浏览器 localStorage，任何人打开浏览器 DevTools 即可读取/篡改/删除 |
| **分享功能仅在客户端** | 🔴 Critical | 分享 token 在客户端生成，数据仅在创建者浏览器中，其他用户打开分享链接永远看不到真实报告 |
| **无数据加密** | 🔴 Critical | 报告数据在本地完全明文，无任何加密措施 |
| **无访问日志** | 🟡 Medium | 无法追踪谁在何时查看/修改了报告 |
| **JSON 注入风险** | 🟢 Low | localStorage 数据为 JSON 格式，但前端使用 `JSON.parse` 解析，无 eval，风险可控 |

### 运营经理补充 — 数据可用性风险

| 风险项 | 影响 |
|--------|------|
| **数据丢失** | 用户清除浏览器数据 = 全部报告丢失，无恢复可能 |
| **无法多设备** | 用户在桌面创建的报告，手机上永远看不到 |
| **无法合规** | ISO 9001 / IATF 16949 要求数据持久化和审计追溯，当前架构不满足 |

## 五、AI Token 骗取风险评估

### 风险经理分析 — ⚠️ 观察项

**当前阶段评估**: 不存在直接的 "AI Token 骗取" 风险通道。理由：

1. **无 AI/ChatGPT API 集成**: 当前 Phase 1 不调用任何外部 AI 服务，没有 API token 可供窃取
2. **无 WebSocket/SSE 长连接**: 攻击者无法通过长连接持续消耗 token
3. **前端代码无 token 暴露**: 所有环境变量（包括 `CREEM_API_KEY` 等）仅在服务端，前端 JS bundle 中无任何 API key

**未来 Phase 2 如果加入 AI 功能时需要注意**:
- 所有 AI API 调用必须经过服务端代理，token 存在服务端环境变量中
- 实施用户级别的 AI 调用频率限制（如每人每小时 20 次）
- 实施 CAPTCHA 或人机验证机制

| 未来风险场景 | 骗取方式 | 防护措施 |
|------------|---------|---------|
| AI 辅助填写 D4 根因分析 | 批量创建报告反复调用 AI API | 每用户每日/每小时调用上限 |
| 自动摘要生成 | 用脚本轮询 API endpoint | IP 级别 + 用户级别双重限流 |
| 报告内容优化建议 | 注入超长 prompt 消耗 token | 输入长度截断 + 超时控制 |
